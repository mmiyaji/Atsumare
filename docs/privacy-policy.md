# Privacy Policy for Atsumare

Last updated: 2026-04-11

## Overview

Atsumare is a Windows desktop utility that helps users identify currently open applications and move app windows between monitors.

This Privacy Policy explains what data Atsumare accesses, how that data is used, and how that data is handled.

## Data Atsumare Accesses

To provide its core functionality, Atsumare may access the following information on the local device:

- Names of currently running processes
- Paths of local executable files for running apps
- Titles of visible top-level windows
- Window placement and monitor information
- App icon resources embedded in local executables or packaged app assets
- User-configured app settings stored on the local device

## How This Data Is Used

Atsumare uses this information only to:

- Display a list of open apps to the user
- Group related windows into app tiles
- Show app icons in the picker
- Move the windows selected by the user to another monitor
- Save the user's local settings and preferences

## Data Transmission

Atsumare does not intentionally transmit window titles, process names, executable paths, monitor layout details, or app selection history to the developer or any third party.

If diagnostic logging is enabled in a development build, logs are written locally on the device for troubleshooting. Release builds are intended to operate without developer-only diagnostic UI.

## Data Storage

Atsumare stores settings locally on the user's device. These settings may include app preferences such as startup behavior, filtering preferences, and related configuration data.

Atsumare does not provide a cloud sync service and does not maintain a remote user account system.

## Data Sharing

Atsumare does not sell, rent, or disclose the local app/window information it accesses to third parties.

## Security

Atsumare is designed to process operational window and app information locally on the device. Users should download Atsumare only from trusted distribution channels and keep Windows up to date.

## Your Choices

You may stop Atsumare from accessing current window and process information by closing the app or uninstalling it.

You may remove locally stored settings by uninstalling the app and deleting any remaining local app data folders, if applicable.

## Children

Atsumare is not directed to children and is intended as a desktop productivity utility.
